What I'm doing now

I lead testing for a state Medicaid program that is moving its core systems from a mainframe to Microsoft Azure. Ensono and Microsoft are our partners.

I manage a team of 6 and a ~$2.4M budget, within a program 3–4 times that size. Testing is layered, so the state has proof at every stage before go-live:

  1. My team baselined every migrated program on the mainframe. Ensono used that baseline to confirm their converted code produces the same data.
  2. My team then tests each function in Azure.
  3. An end-to-end team runs full scenarios with the other vendors.

Health plan and provider testing are complete. I had the team build automated regression tests for both, so coverage continues while we move on. In encounters, the first 62 test cases surfaced 55 defects, all caught before production.

01

Modernizing Legacy Systems Without Disrupting Production

I move critical systems to modern platforms, and I prove they work before cutover.

Mainframe to Azure for a state Medicaid program 2026–present
Problem
A state is moving the systems that pay providers and enroll members from a mainframe to Azure. A mistake would mean wrong payments or lost coverage.
My role
Test Lead & QA Manager. Team of 6, ~$2.4M budget. I work with Ensono, Microsoft, and agency leaders.
What I did
  • Led a layered approach. My team baselined every migrated program on the mainframe, and Ensono validated its converted code against that baseline. My team then tests each function in Azure and hands it to the end-to-end team, which runs full scenarios with the other vendors.
  • Used AI to generate ~2,000 test scenarios across provider, claims and encounters (records of care that health plans report to the state), and health plan enrollment.
  • Had the team automate regression tests for finished areas, so coverage continues while we move to the next functions.
  • Set readiness gates for go/no-go decisions and run defect triage across the agency and partners.
Outcome
  • Health plan and provider testing complete, with automated regression in place.
  • In encounters, the first 62 test cases surfaced 55 defects, all before production.
Skills
Risk management · Test strategy · Test automation · AI-assisted delivery · Partner alignment
